# ToneCraft

> A sleek, minimal AI-powered text transformation utility designed to instantly adapt the tone of any writing. Built with a modern developer-first aesthetic inspired by Vercel and Linear.


---

## ✨ Features

* **Instant Tone Shifting:** Quickly convert text into professional, casual, concise, or persuasive variations.
* **Modern Minimalist UI:** Styled with a dark monochrome backdrop, subtle rim-glows, and clean typography using Plus Jakarta Sans.
* **Persistent Result Card:** Dedicated output display with seamless one-click clipboard copying.
* **Responsive Architecture:** Built with clean structural grid and flex layouts for optimal usability across devices.

---

## 🛠️ Tech Stack

* **Frontend:** EJS (Embedded JavaScript Templates), HTML5, Custom CSS
* **Backend:** Node.js, Express.js
* **Styling:** Custom CSS variables, Flexbox, SVG iconography
